# 🚀 Data Structures Lab

This repository contains Data Structures Laboratory practicals implemented using C/C++.

## 🎯 Course Outcomes

- **CO1:** Implement linear data structures like Stack and Queue.
- **CO2:** Implement linear data structures like Singly, Circular and Doubly Linked Lists.
- **CO3:** Implement and traverse nonlinear data structures like Graphs and Trees.
- **CO4:** Demonstrate and compare different searching and sorting algorithms.

## 🧪 List of Experiments

### Level: Basic

1. Implement the Stack and use it to solve the Postfix Expression.
2. Implement the Circular Queue.
3. Implement a Singly Linked List.
4. Implement a Circular Linked List.
5. Implement a Doubly Linked List.

### Level: Moderate

6. Implement Merge Sort and Bubble Sort.
7. Implement Quick Sort.
8. Implement Binary Search Tree and AVL Tree traversal methods.
9. Implement Insertion Sort.

### Level: Complex

10. Implement Graph and traverse the graph using DFS.
11. Implement Graph and traverse the graph using BFS.
